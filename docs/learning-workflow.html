1. Update the folder you already use

This automatic update is for Tejasvi Campus 3.8.1. You can see the installed version near the top of package.json.

  1. Stop the running Tejasvi app with Control+C. Keep MySQL running.
  2. Back up from your original configured folder with npm run backup. Keep the backup outside the folder being updated.
  3. Extract Tejasvi-Campus-3.9.0.zip. In the new download, open Update-Tejasvi.command.
  4. When Finder asks for a folder, choose the original configured Tejasvi folder you normally run.
  5. In that original folder, open Start-Tejasvi.command. Allow the rebuild to finish, then open localhost:3000/workspaces.
Your accounts, institutions, uploaded files and AI settings remain in the original installation. Start applies migration 024, which adds approval and transfer tables. You do not need another database, college setup or API key.

The updater checks file versions before changing anything and keeps a source backup. It leaves locally changed source files and unsupported older versions untouched. For a genuinely new installation, open Start-Tejasvi.command in the new folder and follow START-HERE.txt; Node.js 24+ and MySQL 8+ are required.

3. Connect work, feedback and results

  1. Open Assessment & progress → Gradebook. Learners use My grades.
  2. Choose the course and open the learner. The page combines published assignments, current quiz attempts and additional college marks.
  3. Choose Review work to open an assignment submission. Return it for revision with feedback, or use Release grade & feedback when it is ready. A released grade is immediately visible to the learner.
  4. Choose Review & approve result. Give the result a title and select the items that belong in it. Every selected item must have a released mark.
  5. Review the preview and choose Approve & release result. The result and its selected items are saved in MySQL as a numbered revision.
Missing work is never silently zero. The provisional percentage uses only graded items. The approved result uses exactly the items you selected, weighted by their maximum marks. For example, 40/50 plus 80/100 becomes 120/150, or 80%.

Quizzes use the latest attempt on the current quiz version, each scored out of 100. An old quiz version does not satisfy a revised quiz. Additional marks are opt-in during approval so you can avoid counting the same activity twice.

If selected marks change later, the approved snapshot remains saved and is marked as changed. Review and approve a new revision before transferring the revised result. The interface shows the latest revision; earlier snapshots remain in the database. Export marks downloads the visible gradebook to CSV.

4. Send an approved result for examination review

A school or college administrator with EMIS administrator access can transfer an approved result. The Learning course must have an exact subject link to the EMIS course; matching names alone are not enough.

  1. In EMIS, open the Learning overview, expand Teaching allocations and use Publish subject for the course and create an examination for that course if one does not already exist.
  2. Confirm that the learner’s shared EMIS enrollment is active in the examination’s academic year, program and semester.
  3. In the learner’s approved gradebook result, choose Transfer to EMIS.
  4. Select the matching examination and review the scaled marks. For example, 120/150 becomes 32/40 when the examination maximum is 40.
  5. Choose Create EMIS draft result. Open EMIS Results & assessment to review and publish through the normal examination workflow.
A transfer creates a Draft. It never automatically publishes an official result or overwrites an existing student–examination result. Repeating the same transfer returns the same record. If marks were already transferred and later revised, review the existing EMIS result through its normal correction process.

No matching examination? Check the exact subject mapping, academic year and student enrollment. A separately created Learning course is not automatically paired to an EMIS course by its title.

5. Notice who needs support

Open Assessment & progress → Learning progress (learners: My progress). Search by learner, email, institution ID or course; filter by course and status.

  • Not started includes authorized learners who have no completed reading, submission or current quiz attempt. They are not omitted because they have no activity.
  • Lesson reading counts standalone lessons and published units. Reading percentage is separate from marks.
  • Quiz progress counts current quizzes passed at the existing 70% threshold.
  • Follow-up reports overdue tasks, requested revisions and quiz scores below 70%.
  • Learning completed requires at least one reading item, all published reading items completed, current quizzes passed and published assignments graded. It is a learning status, not an official qualification.

Use Export view for the filtered CSV. A teacher’s roster is limited to their assigned courses and individual learners; a learner sees only their own records. EMIS students who still need a login or Learning class assignment remain visible in Student directory, rather than appearing as learners with access they do not yet have.

6. Run one class through the complete flow

  1. As administrator, confirm one real student in Student directory, activate or link their login if needed, and assign their Learning class and subject.
  2. As teacher, publish a course with a lesson, quiz and assignment.
  3. As student, open the course, complete reading, take the quiz and submit the assignment.
  4. As teacher, return the assignment for revision; as student, revise it; as teacher, release the mark and feedback.
  5. Check My grades and My progress as the student. Confirm another student’s records are unavailable.
  6. Approve a result as teacher. As administrator, transfer it to a linked EMIS examination and verify its Draft status and scaled mark.

These checks used disposable test records. Your Mac and your institution’s existing data still need the one-class check above.
