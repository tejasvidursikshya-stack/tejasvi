TEJASVI CAMPUS · MAC PILOT · 3.6.0

Activate Tejasvi AI

Connect the Mac once. Then choose which institutions and roles may use each feature.

1. Update the application

  1. Stop the running Tejasvi app with Control+C. Keep MySQL running. In your original configured folder, run npm run backup to back up the database and uploads.
  2. Unzip Tejasvi-Campus-3.6.0.zip. In the new folder, open Update-Tejasvi.command. Choose the original, configured Tejasvi folder you normally run.
  3. For a brand-new installation, use Start-Tejasvi.command in the new folder first. Create your Super Admin and your school, college, company or provider.

Create PowerPoint presentations with Gamma

Teachers and trainers can design decks from a lesson brief or bring over the learner-facing slides from a Studio draft. Students open the reviewed PowerPoint inside their course without a Gamma login.

  1. Connect once on the Mac. In Gamma, open Settings and members → API keys → Create API key. In the Tejasvi folder that normally launches your institution, open Configure-AI.command → 4 — Gamma. Paste the Gamma key at the hidden prompt. The helper checks access without creating slides. Restart Start-Tejasvi.command in the same folder.
  2. Enable an institution. As the platform Super Admin, open Learning → Tejasvi AI → Connections → Check Gamma connection. Turn on Enable Tejasvi AI for this organization and Gamma presentations. Choose an optional Gamma theme for the institution and click Save access. A theme can supply the school or company’s colors and fonts. Each institution starts with Gamma switched off.
  3. Try a lesson. Go to Presentations → Use Java example, or enter a title, audience and teaching notes. For example: Show BCA second-semester students how one Java class can create two objects with different values; finish with a trace-the-output question. Choose 6, 8, 10 or 12 slides and whether to generate illustrations. English and Hindi are available here. For a Nepali deck, use Tejasvi’s regular Create → Slides workflow. If you already have a Studio draft, choose its Slides output and Design with Gamma.
  4. Generate and review. Check the consent box and click Generate presentation. This sends the visible brief to Gamma and can use Gamma credits. Don’t include private learner records. Use My presentations to reopen an in-progress job rather than submitting it again. Once ready, use Preview slide text or Download PowerPoint to review the full designed deck.
  5. Share a course copy. Pick a published course you teach, confirm your review, then click Share to course. Assigned learners find the file under the course’s Resources. If you revise the file in PowerPoint or the connected Gamma account, upload the edited .pptx and choose Update course copy. Withdraw removes the course copy. Other courses and the teacher’s original are independent.

What stays private? Tejasvi requests a Gamma document with link and workspace sharing turned off. Opening the editor requires access in the connected Gamma account. Course members get the reviewed file through Tejasvi, not a Gamma editor link. The integration stores ownership and request history in MySQL and saves validated files in protected uploads.

If a deck is delayed: reopen the same presentation and choose Check progress. If Gamma could not confirm receiving the request, check the Gamma account before generating again. If an export expires, is too large or comes from a storage host Tejasvi cannot verify, open the deck in Gamma, export it as PowerPoint, then upload a reviewed copy (up to 20 MB). If the key or credits are rejected, use Connections to check the Gamma workspace. Your OpenAI and Wayne settings are separate.

2. Connect OpenAI on the Mac

  1. Create or select a project in the OpenAI API dashboard. The project needs API credit or billing and access to the models you choose.
  2. In your configured Tejasvi folder, open Configure-AI.command. Choose 1 — OpenAI. Paste the project key into the hidden Terminal prompt; press Return. Keys belong on this Mac, never in a chat or teaching brief.
  3. Press Return to accept the suggested text model (gpt-4.1-mini) and audio model (gpt-audio-1.5), or enter models your API project can access. The text model must support the Responses API and structured outputs; the audio model must support Chat Completions with WAV output.
  4. Restart Start-Tejasvi.command in this same folder. Open My workspaces.

3. Enable one organization

  1. Sign in as the platform Super Admin, select the institution you administer and open Learning → Workspace → Tejasvi AI → Connections.
  2. Use Check text model and Check voice model. These check key/model access without asking the models to generate anything. They do not check remaining credits.
  3. Turn on Enable Tejasvi AI for this organization. Enable Staff narration and narrated lessons for downloadable voice and narrated films. Enable Learner conversations only when students or employees should have access. Click Save access.

Organization settings apply immediately. Restart the app only after changing the server credentials or models. Previous installation allowlists still apply until the Super Admin saves settings for that institution.

4. Try the first lesson

Create

Choose Content creator, Lesson video, topic “A closed electric circuit,” and audience “Grade 8 science.” Choose a language, confirm you may send the brief, then click Generate draft. Without a key, choose Start a writing draft.

Saved drafts

Open the lesson. Change the output to review slides, quiz, worksheet, flashcards, video scenes or a plan. Save edits. Import or publish only after review. For the video output, Make a narrated video brings the scenes into the recorder.

Voice & video

Under Record a lesson, enter a title and a short script for each scene (up to 650 characters). Choose language and voice, confirm, and click Generate scene voice for each. Listen and check the pronunciation, especially in Nepali. Each recording has a Download WAV link. Saved recordings are private to the author and institution.

Export & share

After checking every scene, select the review box and Render narrated video. Keep the browser tab visible. Download the WebM or MP4 offered by the browser, or expand Share or withdraw a course film, select a published course, review and share. Learners with course access see it under Lesson films. Direct course sharing supports films up to 12 MB; longer films can still be downloaded. Render without sound works without an AI key.

Ask & Talk

Ask gives text answers and can use excerpts from an accessible course. Voice & video → Live conversation → Open voice chat lets staff speak or type; learners open Voice & video directly. Microphone recognition and installed voices depend on the browser and device. This mode reads answers aloud; it does not save a narration file.

Optional: a live video presenter

Sandbox · Wayne: “could not find the configured voice for this key”? Update your existing installation to 3.6.0, restart it, then run Check LiveAvatar setup. If the old voice is unavailable, Tejasvi asks LiveAvatar for Wayne’s default and verifies it. The check names the voice that will be used. This does not change the saved Live voice or start video.

If Start video session is grey: the organization switch allows access, but each person must also agree to that session. Since Campus 3.5.1 the checkbox is directly above Start. In 3.5.0 the preview can cover it on shorter screens; update the app or zoom out in the browser until you can tick Enable video.

  1. Open Connections as the platform Super Admin. Entered only means the server has local settings. Click Check LiveAvatar setup to verify that the LiveAvatar API key can read the effective avatar, voice and optional context. In Live mode the check also tries to verify that credit is available. It does not start a session or test browser playback.
  2. If no usable voice is found: open Configure-AI.command in the folder that runs Tejasvi. Choose 2 — LiveAvatar, press Return to keep your key and answer yes for Sandbox. At the voice menu choose 2 — Choose from my voices. Select a voice by number; use N for the next page or T for private voices. The helper verifies your selection before saving. Keep the context if unchanged and restart Start-Tejasvi.command. If neither voice library has a usable entry, add or bind a voice in this same LiveAvatar account first.
  3. When to use Live: Sandbox uses Wayne for up to one minute without live credits. For production, select Live and its own avatar and voice. Tejasvi never substitutes another voice for a missing, explicitly selected Live voice. Optional context is separate; enter a dash only if you want to clear it.
  4. In the correct institution, enable Tejasvi AI and Live video presenter, then Save access. Learners also need Learner conversations.
  5. Open Tejasvi AI → Voice & video → Live conversation → Open live presenter (learners open Voice & video directly). Tick I agree to start this presenter session, then click Start video session. Wait for the video. Type a question or choose Speak. If prompted for microphone access you can decline and type instead. Use End session when finished.

Room connects but no picture? Use Play video & enable sound if offered. If the presenter still cannot stream, try a network that permits WebRTC rather than starting repeated live sessions. The dialog distinguishes a token rejection, a browser connection failure and a room that connected but did not deliver a video frame.

If something stays off

  • No Connections settings? Use the platform Super Admin with an administrator membership in that institution. Organization admins and teachers cannot enable provider spending.
  • Key or model missing? Run the helper in the original folder and restart that folder’s launcher. A model check failure points to credentials, project permissions or network access. A generation limit error may mean the provider needs credit.
  • Cannot hear or use the microphone? Use localhost or HTTPS, allow microphone and sound, and check browser language support. Typed chat still works. Exported lessons need no microphone.
  • No film export or share button available? Try desktop Chrome, keep the tab visible and review a recording for each scene. Sharing needs a published course you can edit. A learner can watch shared films even if learner AI generation is off.
