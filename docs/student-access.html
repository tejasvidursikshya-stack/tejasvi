Find an EMIS student in Learning

One enrollment record, one shared login when activated, and a separate class assignment for learning.

Find a student who is already enrolled

Open your running installation at http://localhost:3000/workspaces (or your school’s Tejasvi address). The downloaded dashboard preview contains sample records and cannot show your MySQL data.

  1. Sign in as an Admin or Super Admin of the same school or college. Open Learning → People & organization → Student directory.
  2. Choose the academic year used in EMIS. Leave login status and Learning class on All. Search by student ID, email or name.
  3. The row shows the EMIS program, semester or intake and the Learning login status. Return to the tab or choose Refresh after changes in EMIS. You don’t need to import the student again.

For a new applicant, open the accepted application in EMIS and choose Enroll this student → Confirm enrollment. The confirmation has an Open student in Learning link for administrators.

Give the student access

StatusWhat to do
Needs loginChoose Activate login and verify the student’s own email. A new account gets an individual temporary password. Copy it privately before closing; the student changes it at first sign-in. No invitation email is sent.
Existing loginIf the app finds an existing account, confirm its owner and choose Link existing login. The student keeps the same email and password.
Login activeChoose Assign to intake for college or Assign to batch for school. Select the actual Learning class and subjects, then Save assignment. This adds to existing assignments.
Access pausedReview the student’s enrollment status and EMIS → Users & access. Viewing or refreshing the directory does not reactivate a paused account.

If the row or lessons are missing

No student row? Check the institution and academic year in both apps, clear filters, and look in the EMIS student register. An enquiry or accepted application alone is not an enrollment. Accounts and course rosters are narrower lists than the institution’s student directory.

Student can sign in but sees no course? Verify that the intended course is published and available to the student. For a college subject restricted to an intake, assign the intake and subject, and offer the published course to that intake. An EMIS batch description alone does not grant course access.

Duplicate or mismatched identity? Review the original EMIS student IDs and email before linking. Do not create another account as a workaround. Historical records can be viewed; activate a login from the current active enrollment.
