# Homepage teaching gallery

The six photographs are original project assets generated with the built-in image generation tool. The reference screenshot informed the layout only. The photos contain no application labels: captions and examples are rendered as accessible HTML.

- Component: `components/campus-home/teaching-gallery.tsx`.
- Images: `public/assets/teaching-gallery/`. Each format has a desktop WebP and a smaller `-small.webp` file.
- Styling: `app/teaching-gallery.css`. Motion is optional, and every sample opens by keyboard or touch.
- Build the self-contained preview with `npm run preview:homepage -- --gallery`. Without `--gallery`, the preview starts at the top of the homepage.
